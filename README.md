
# LibMan — Hệ thống quản lý thư viện

Ứng dụng web Java cài đặt hai module **Reader Search Document 7** và **Borrow Document 7**, kèm đăng nhập, đăng xuất. Giao diện dùng JSP, HTML, CSS và JavaScript; Servlet điều phối yêu cầu; DAO truy cập MySQL; model đóng gói dữ liệu.

## Chức năng

**Reader Search Document 7:** Bạn đọc tìm tài liệu theo tên hoặc một phần tên; xem danh sách kết quả, thông tin chi tiết, các bản tài liệu, vị trí kệ và trạng thái; quay lại kết quả với từ khóa đã tìm.

**Borrow Document 7:** Nhân viên xác định bạn đọc bằng số thẻ, kiểm tra điều kiện mượn, thêm/bỏ các bản bằng mã vạch, hủy lượt mượn hoặc lưu phiếu. Khi lưu thành công, hệ thống cập nhật trạng thái bản, hiển thị phiếu để in và hoàn tất.
